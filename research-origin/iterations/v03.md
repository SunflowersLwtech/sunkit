# Iteration V03 — Knowledge Layer Engine + Successor Frameworks

**Date:** 2026-04-06
**Focus:** Integrate three-layer knowledge model + Dreyfus/Collins/Nonaka
**Status:** Eval in progress

## Motivation

User provided images showing the knowledge iceberg (Explicit/Implicit/Tacit) and its
relationship to prompt engineering as a knowledge conversion process. Key insight:

> 越容易编码的知识，越容易被AI替代。隐性知识的提取能力变成核心竞争力，
> 而默会知识则是人机协作的长期边界。

Combined with analysis that Polanyi's philosophical contributions were operationalized
by three successors: Dreyfus (skill acquisition), Collins (tacit taxonomy), Nonaka (SECI
and its misreading).

## Major Changes

### 1. NEW: System 1 — Knowledge Layer Engine
Added as the first system, before the lenses. Forces the skill to:
- **Classify every piece of advice** by knowledge layer (explicit/implicit/tacit)
- **Skip explicit knowledge** — don't waste tokens on what's in the docs
- **Spend tokens on implicit** — extract the unspoken "why" behind expert decisions
- **Push toward tacit** — use embodied/holistic/situational diagnostics

### 2. NEW: Collins' Taxonomy
Three types of tacit knowledge with AI capturability:
- Relational (extract aggressively — it's just missing documentation)
- Somatic (approximate via gestalt principles and embodied metaphors)
- Collective (surface community standards, but acknowledge the living standard evolves)

### 3. NEW: Dreyfus Calibration
Detect user skill level, calibrate depth accordingly:
- Novice → explicit rules ARE helpful
- Competent → surface implicit reasoning
- Proficient → challenge with tacit edge cases
- Expert → offer a lens they haven't used

### 4. NEW: Anti-SECI Awareness
Explicit instruction NOT to pretend all expert judgment can be codified.
Acknowledge the boundary honestly when you hit it.

### 5. Restructured as 4 Systems
```
System 1: Knowledge Layer Engine (WHERE to operate)
System 2: Six Reasoning Lenses (HOW to analyze)
System 3: Operating Procedure (WHEN to apply what)
System 4: Quality Standards (HOW to output)
```

## Expected Impact
- Higher TA scores (tacit articulation) due to knowledge layer awareness
- Maintained AC scores (V02's fix preserved)
- More nuanced responses that skip tutorial-level advice
- Better calibration for specification vs diagnostic prompts
