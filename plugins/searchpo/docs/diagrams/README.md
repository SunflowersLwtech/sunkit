# Diagrams

This directory stores diagram source files and their reviewable exports.

## File Policy

- Keep the editable source as `*.drawio`.
- Keep the final exported image as `*.drawio.png` when the PNG embeds the draw.io XML.
- Do not keep transient preview exports unless a document explicitly references them.
- Name files by system scope and subject, for example `searchpo-main-agent-architecture.drawio`.

## Current Diagrams

- `searchpo-current-architecture.drawio`: source for the full Searchpo runtime architecture, including the three-agent split, research enrichment, render/audit, and Douyin release boundary.
- `searchpo-current-architecture.drawio.png`: final exported PNG with embedded draw.io XML.
- `searchpo-main-agent-architecture.drawio`: source for the main-agent-centered Searchpo runtime architecture diagram.
- `searchpo-main-agent-architecture.drawio.png`: final exported PNG with embedded draw.io XML.
