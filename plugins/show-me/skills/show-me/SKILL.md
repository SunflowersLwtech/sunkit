# show-me — 信息放在图上，正文只补图说不了的

**交付物是一个自包含页面，信息主体在图上。** 读者先看图，看完图就该拿到大部分结论；
正文只装图表达不了的那一点。

要覆盖的错误默认：写一篇结构漂亮的长文——小标题、五列对照表、每格好几句话——
再配两三张「目录图」，图上只有框和名字，数字、约束、状态全在下面的段落里。
那样读者还是得通读，图等于没画。

**判据：把正文全遮住只看图，读者能不能回答这一页要回答的问题？** 不能，就是信息没上图——
改图，不是加字。

## 1. 先定图

**一句话写出这张图要回答的那一个问题。** 写不出来就还不该画。有了这句话才选形状：
结构 / 时序 / 状态机 / 分层 / 对比矩阵 / 数据图表；超过 9 个节点通常是两张图。

不画的四种情况：

- 答案是一句话或一个数——直接说。
- 内容天然是「行 × 列」且行之间**没有方向**（流向、依赖、时序、因果）——用表格。有方向就画。
- 只有一个形状——写那句话。
- **格子里该填什么你还不知道**——想画能力矩阵，却没有能测那些格的量具。图的形状会替你把空白
  填成断言。换一张能诚实作答的图（定位 / 取舍），并在说明里写一句换了什么。

**交付物本身是 UI/UX 提案时，图是高保真 mockup，不是线框**：用 HTML/CSS 借目标产品的真色板和
真组件形状画（照抄别家产品前先核它的 design tokens）。引入了多态（步骤条、stage）就每一态都出稿。

## 2. 让图承载信息

框和名字只是骨架。读者要的数字、状态、约束，都优先找图上的位置：

- **数字标在图上**：连线标次数 / 延迟 / 流量 / 比例，节点标容量 / 版本 / 数量 / 时限。
  「约 3 秒」「最多 4 个并发」这种句子，属于连线和节点，不属于段落。
- **用视觉通道编码，不用文字描述**：颜色 = 状态（缺 / 部分 / 有），线型 = 同步 / 异步 / 可选，
  粗细 = 量，位置 = 阶段或层级。图例只定义一次，放第一张图。
- **对比画成矩阵图或并排小图**，不做每格塞句子的表格。「三家 × 七环节」是一张格子图：
  格子里是色块 + 不超过 6 个字的标签，细节差异用格子角标编号引到图下的一行说明。
- **反直觉的那一条画成 callout**，指向它所在的节点。那通常是这张图存在的理由。
- **失败模式画在图上**：断掉的边用虚线 / 红叉标出，旁边写一句「断了会怎样」。
- **量化内容用图表**（柱、线、带、散点），不用「大约 X、高于 Y」的句子。
- **装不下就拆图，不溢出到正文。** 单图上限是 diagram-design 的预算（≤ 9 节点、≤ 2 条 callout）；
  超了就拆成「总览 + 细节」，读者要回答几个问题就画几张图。

## 3. 正文预算（硬上限）

| 位置 | 上限 |
|---|---|
| 页首结论 | ≤ 3 句，每句一个判断 |
| 每张图的说明 | 图注 1 句（这张图回答什么）+ ≤ 3 句图上画不出来的东西（机制原因、出处、限制） |
| 表格 | 只给真正的行 × 列数据；每格 ≤ 一个短语（约 10 字）。格子里要写句子，说明它该是图，或者该删 |
| 待决事项 | 每项一行：问题 + 选项 + 你的建议 |

**不写**：过程（测了什么、试了几轮）、被砍清单、复验清单、「未验证 / 会过期」表、方法论段落、
复述图上已经看得见的东西。只有**会改变读者决定**的风险才写，一行，放在相关那张图的说明里。

**超预算 = 信息没上图**，回 §2，不是砍掉信息。底线：读者据此做决定要用的数字一个都不能丢——
先在图上找位置，图上实在放不下才进说明。原始材料里没正面说过的，标「推断」。

## 4. 多图页面：勾连与自包含

- **同一套标识符贯穿**：总览图的节点编号 / 名称 = 细节图标题 = 说明里的引用。正文引用的编号必须
  画在画布上；每张图的图注写它对应总览图的哪个节点。
- 同一状态在每张图里同色同线型。
- 页面内跳转用 `id` + `href="#id"`；id 只用字母、数字、`-`、`_`（这套字符到哪个平台都安全）。
- 所有图内联在同一个文件里，不引用本地路径或外链图片；每张图单独截出去也能读。

## 5. 交给谁画、交成什么格式

**先按读者怎么看选渲染器：**

| 读者怎么看 | 交给 | 交出去的 |
|---|---|---|
| 给某个人讲清一个复杂问题的单页讲解——流程、对比、排查结论，不需要精细定制图 | answer-me-with-html（am） | 离线单文件 HTML（直接发文件，或放到任一静态托管出链接） |
| 手机、聊天窗口、进文档的一张图（默认） | /diagram-design:diagram-design | PNG，或嵌在页面里的 SVG |
| 在电脑上反复点着看的系统图——架构、数据流、时序、工作流、状态机、ER、时间线、耗时瀑布（拖动缩放、点节点看上下游） | archify | 交互 HTML **加**同一份材料的静态版：`scripts/archify-page.mjs` 拼的页面，每张图 = 整图 SVG + 卡片 + 「全屏打开交互版」，手机读者看静态那一半 |
| 拿不准、要数据图表（柱 / 线 / 散点）、或本机没装 archify / am | diagram-design（它也没有就按 §2 手写 SVG/HTML） | — |

**archify 和 answer-me-with-html 不在 / 菜单和 skill 列表里，是有意的**：本市场把它们的条目标成
`defaultEnabled: false`，装上就是禁用的，对外只留 show-me 一个入口。别启用它们、别找 `/archify:*` 或
`/answer-me-with-html:*`——按 [`references/tooling.md`](references/tooling.md) D 节（archify）/ E 节（am）
source 环境脚本、读它的 SKILL.md 照做。
选 archify 之前想清楚代价：**慢**（每张图几轮 finalize，三张图约 15 分钟）、**大**（每张交互图约 0.8 MB，
拼页后约 1.3 MB）、**桌面优先**（窄屏只保证不溢出，architecture 在手机上被裁）。
读者只用手机看就别选它。am 的代价小得多（一次渲染出一个静态单文件页），但图是自动布局、不能精修——
要控制每个节点位置就别选它。

- **单张图的类型、几何、配色交给渲染器**（diagram-design 或 archify）；页面外壳、多图之间的编号与
  配色一致性归你。diagram-design：取它产出的 `<svg>` 嵌进页面；首次会问要不要定制品牌皮肤——
  **默认答「用默认」，别拿去问用户**，除非用户自己提过品牌色。archify：页面由 `archify-page.mjs`
  拼好，你只往里补页首结论和图注（§3 的预算照样算）。
- **格式跟着落点走**：分享链接 / 手机看 → 自包含 HTML 本身就是交付物，放到任一静态托管
  （GitHub Pages、Netlify、对象存储……）给出链接，或直接把文件发出去——**别拿聊天平台或 IDE 自带的
  画布 / artifact 功能代替交付文件**，那种页面长在平台里，拿不回文件、也没法迭代；
  聊天工具 / 笔记工具 / 文档 → PNG；
  要进 Figma / 要可编辑 → SVG。**导出 PNG 只带 `<svg>` 那一块**，页头和说明全丢——
  交 PNG 时数字必须已经在图上，这正是 §2 的理由。
- **交付前把页面渲染出来看一眼**（截图），验证脚本全绿不等于几何没问题。
- 工具坑全在 [`references/tooling.md`](references/tooling.md)：diagram-design 调不到时怎么手动执行、
  几何验证脚本在中文图上的假绿、交付格式与更新已发布页、PNG 导出依赖链、简中字体与国内网络、
  archify 的调用与坑（D 节）、am 的外联清单（E 节）。**导出、发布、跑验证、调 archify / am 之前读对应那一节。**

## 6. 交出去之前

- **遮住正文测试**：只看图，能答出页首那几句结论吗？
- **数一下预算**：页首几句、每张图说明几句、表格每格多长。超了回 §2。
- **词汇按读者定，不按你手里的材料定**：给负责人、老板、客户看的页，默认读者不看代码——页面上（含图里的字）
  不出现实现标识符：文件路径、函数/表/环境变量名、命令参数、协议状态码、数据源的字段或属性号、库名、托管平台名、
  字节数与格式规格。机制用白话讲（「官网不让我们的程序读」不是状态码，「图太大」不是 64KB），非说不可的概念在第一次出现处用一句白话讲清；标识符留给 PR 和开发笔记。
  给工程读者的页，内部术语也要在图里或图外引入一次——标题和标签都不算引入。
- **悬空指代**：搜 `这两|那两|上面|前面|上述|如前`，对话里成立的指代落到纸上就是凭空冒出来的。
- **自包含、无过程痕迹**：读者打不开的东西等于不存在；「本次调研」「另一次会话实测」之类删掉，
  对外交付物不留 agent 痕迹（署名行、生成过程说明、内部会话梗概都算）。

## 7. 停止条件

- **覆盖已有的图或文档前先读它**，里面有别人加的内容就停下来问。
- 用户只是要个答案、没有外部读者时，别做成交付物。
- 导不出 PNG、图拆不下来、字体没法控——报出来，**不要默默换成一篇文档交差**。
- archify 的环境脚本报错（没装插件、没浏览器）——报出来，改用 diagram-design 出静态版；
  **别自己装浏览器、别 enable 插件**（前者要下载、先征得用户同意，后者会让 archify 以斜杠命令的
  形态出现在每个会话里）。
