# Iteration V01 — First Enhanced Version

**Date:** 2026-04-06
**Focus:** Core framework — transform role-play into cognitive operating system
**Status:** Eval in progress

## What Changed from Original

The original `polanyi-skill` by enzyme2013 was a **role-play simulator** — it made Claude
pretend to be Michael Polanyi. Our V01 is a **cognitive operating system** — it adds
reasoning lenses that actually change how the AI analyzes code and design problems.

### Key Differences

| Aspect | Original | V01 |
|--------|----------|-----|
| Mode | Role-play (first person "I am Polanyi") | Cognitive enhancement (apply lenses) |
| Domain | General philosophy Q&A | Software engineering + UI design |
| Structure | 6 mental models + 8 heuristics | 6 operational lenses with diagnostic questions |
| Output | Philosophical commentary | Concrete code/design analysis |
| Actionability | Low (explains concepts) | High (identifies issues + provides fixes) |
| Tacit knowledge | Talks ABOUT it | DEMONSTRATES it (articulates expert intuition) |

### The 6 Lenses

1. **Subsidiary-Focal Analysis** — Is the framework/boilerplate transparent to the business logic?
2. **From-To Integration Stack** — Are abstraction layers clean? Any boundary violations?
3. **Indwelling** — Will this API/UI become an extension of the user's thought?
4. **Gestalt Integration** — Does this integrate into a coherent whole? (Gestalt principles for UI)
5. **Tacit-Explicit Spectrum** — Translate expert "feel" into actionable feedback
6. **Post-Critical Judgment** — Know when to follow vs break conventions

### Operating Procedure

Added domain-specific application orders:
- Code review: Subsidiary-Focal → From-To → Indwelling → Tacit-Explicit → Post-Critical
- UI design: Gestalt → Subsidiary-Focal → Indwelling → Tacit-Explicit → Post-Critical
- API design: Indwelling → From-To → Subsidiary-Focal → Post-Critical

### Quality Standards

Added 6 hard rules:
1. Never advise without explaining the tacit reason
2. Prioritize focal over subsidiary concerns
3. Preserve the felt dimension
4. Be concrete (principles must land in specifics)
5. Know when to break rules
6. Serve the whole, not the parts
